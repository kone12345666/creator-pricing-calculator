# 飞书与权限配置

## 现有数据不迁移

网页继续连接当前正在使用的飞书多维表格；不需要新建或替换项目表、达人表，也不影响同事直接在飞书中编辑。

## 服务器需要的配置

配置项见仓库根目录 `.env.example`。真实值只能保存到服务器的密钥管理系统或受权限保护的环境文件，不能提交到 Git。

- `FEISHU_BASE_TOKEN`：现有多维表格标识；
- `FEISHU_PROJECT_TABLE_ID`：项目表标识；
- `FEISHU_CREATOR_TABLE_ID`：达人表标识；
- `FEISHU_BASE_URL`：供页面“打开多维表格”使用的地址；
- `FEISHU_APP_ID`：当前企业自建应用的 App ID，可作为部署交接标识；
- `LARK_PROFILE`：本机 `lark-cli` 中专用应用配置的名称；
- `LARK_IDENTITY`：使用应用身份时设置为 `bot`；
- `LARK_CLI_PATH`：本机 `lark-cli` 命令路径，可留空使用默认位置。

## 已验证的本地应用身份

本地验证已改用独立的企业自建应用，不再使用个人用户授权。应用只需要以下应用身份权限：

- `base:record:read`：读取项目和达人记录；
- `base:record:create`：写回新增达人；
- `base:record:update`：更新已有项目及达人记录。

不需要授予删除记录、删除表格、管理文档权限。应用还必须能够访问现有多维表格；建议使用项目表和达人表的只读调用验证授权是否生效。

本地运行时，App Secret 由 `lark-cli` 的本机安全配置保存，不写入 `.env`，更不能提交到 Git。

当前交接应用为“达人保量报价测算”（App ID：`cli_aafafde807f8dd14`）。仓库记录该 App ID、权限清单和接入方式；App Secret 仅应由应用创建者和内网部署人员在安全渠道中交接。

## 公司内网部署

正式服务器不建议依赖个人电脑上的 `lark-cli` 配置。部署人员应从服务器密钥管理系统读取同一个企业自建应用的 App ID 与 App Secret，并将同步适配层切换为飞书服务端 OpenAPI 调用；业务计算、冲突检查和写回保护逻辑可继续复用。

同事拥有文档编辑权，并不会自动让服务器具备 API 写入权；服务器身份需单独授权。

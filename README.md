# 达人报价测算器

用于短视频达人采买的内部报价测算工具。输入采买成本、客户 CPM、自然播放和目标毛利率后，可自动计算 KPI 播放量、保量成本、建议卖价与实际毛利。

本仓库是供技术评审与内网部署准备的脱敏源码：不包含任何真实项目、达人数据、飞书登录状态或密钥。

## 已实现功能

- 多项目切换与飞书多维表格同步；
- 达人采买成本、客户 CPM、自然播放、其他成本、毛利率的实时测算；
- 当前报价、建议价、批量恢复建议价与 KPI 播放量联动；
- 写回前变更清单、冲突复核、项目 ID 确认；
- 新达人追加写入、抖音号去重；
- 本地删除不会删除飞书记录。

## 本地启动

需要 Node.js 22.13 或更高版本。

1. 复制 `.env.example` 为 `.env.local`，填写飞书相关配置。
2. 安装依赖：`npm ci`
3. 启动：`npm run dev`
4. 在浏览器打开终端提示的本地地址。

未配置飞书时，页面仍会展示匿名演示数据；同步和写回接口会明确提示缺少配置。

## 安全约定

- 不提交 `.env`、`.env.local`、个人飞书登录状态、真实多维表格标识、业务快照或 FAQ 录屏素材。
- 正式内网部署时，飞书读写应切换为公司自建应用身份；当前 `lark-cli` 的个人身份模式仅保留作本地过渡验证。

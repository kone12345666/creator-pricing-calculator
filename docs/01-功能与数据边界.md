# 功能与数据边界

## 页面能力

页面从飞书多维表格读取项目与达人明细，并在浏览器本地完成报价计算。核心关系为：

- KPI 播放量 = 当前报价 ÷ 客户 CPM × 1000；
- 保量成本由 KPI 播放量与保量成本 CPM 推导；
- 建议卖价在满足客户 CPM 与目标毛利率的前提下计算；
- 无法同时满足时，页面给出保本价与风险提示，不会输出 0 元报价。

## 写回边界

- 写回前展示变更清单；
- 提交时必须填写与项目一致的项目 ID；
- 后台再次读取飞书，对比项目参数和达人字段；有冲突时拒绝覆盖；
- 新达人以抖音号在项目内去重，并追加为新记录，关联到当前项目；
- 页面删除达人只影响本地待测算列表，不删除飞书记录。

## 数据归属

业务数据以现有飞书多维表格为准。仓库中的 `app/feishu-snapshot.ts` 是匿名演示数据，仅用于飞书暂不可用时展示页面。

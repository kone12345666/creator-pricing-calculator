# 验收清单

## 读取与计算

- 可以从项目下拉框读取多个项目；
- 切换项目后，全局参数与达人明细均来自对应飞书记录；
- 修改客户 CPM 或当前报价后，KPI 播放量正确联动；
- 点击“批量恢复建议价”后，所有达人按最新全局参数重新计算；
- 毛利无法达标时，显示保本建议和风险状态，而不是 0 元报价。

## 写回保护

- 写回前展示项目参数、达人更新和新增达人的变更清单；
- 项目 ID 不匹配时拒绝写回；
- 飞书中的数据被他人修改后，写回提示冲突且不覆盖；
- 新达人包含项目关联和“是否参与计算”；
- 同项目抖音号重复时拒绝新增；
- 本地删除达人后写回，不删除飞书中的原记录。

## 运维与安全

- 外网无法访问；
- 未配置飞书参数时，接口返回明确错误，不泄露配置值；
- 日志中不出现 App Secret、个人令牌或完整业务数据；
- 服务重启后可恢复；
- 有可回滚的上一版本和数据备份策略。

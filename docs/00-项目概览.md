# 项目概览

## 目标

帮助业务同事在短视频达人采买前，快速判断报价是否同时满足客户 CPM 要求与内部目标毛利率，并降低手工计算和写回飞书时的错误风险。

## 核心术语

| 术语 | 说明 |
| --- | --- |
| 客户 CPM | 客户允许的每千次播放报价口径 |
| KPI 播放量 | 根据当前报价与客户 CPM 自动反推的保量播放目标 |
| 保量成本 | 当视频自然播放不足时，为完成 KPI 所需承担的成本 |
| 建议价 | 满足客户 CPM 与目标毛利率时的建议卖价 |
| 保本价 | 无法达到目标毛利率时，避免亏损的最低报价参考 |

## 数据来源与职责

- 飞书多维表格：项目参数、达人资料与最终业务记录；
- 报价测算器：计算、风险提示、变更预览和受保护写回；
- 业务同事：确认项目参数、报价与写回内容；
- 技术与 IT：部署、权限、日志和版本管理。

## 版本状态

当前为 `v1.0.0` 技术交接版本。它保留已验证的业务功能，并完成了仓库脱敏；正式内网推广前，仍需完成公司飞书自建应用身份、公司访问控制和审计日志接入。

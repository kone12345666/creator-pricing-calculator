# 内网部署建议

## 推荐结构

```text
同事浏览器 → 公司内网 HTTPS 域名 → 前端页面 + 同域 /api 反向代理 → 飞书同步服务 → 飞书多维表格
```

前端构建时设置 `NEXT_PUBLIC_SYNC_ROOT=/api`。反向代理将 `/api/*` 转发到同步服务的 3001 端口，使飞书接口不直接暴露给员工浏览器。

## 环境要求

- Linux 服务器：建议 2 核、4GB 内存、20GB 磁盘；
- Node.js 22.13 或更高版本；
- 公司内网域名和 HTTPS 证书；
- 服务器允许访问飞书开放平台；
- 仅向内网开放 443 端口；同步服务端口只允许本机或反向代理访问。

## 上线前必须完成

1. 配置公司自建应用身份，替代个人 `lark-cli` 登录；
2. 将真实配置放入服务器环境变量或密钥管理系统；
3. 接入公司 SSO、VPN 或网关权限，限制可访问人员；
4. 给写回行为保留审计日志；
5. 在测试环境验证读取、冲突拦截、新达人追加和写回后，再切换正式域名。

## 当前技术限制

仓库已完成脱敏和环境变量化，便于技术评审；但尚未包含公司飞书自建应用的服务端凭证适配、公司登录和生产审计日志。这三项应由部署前的生产化改造完成。
